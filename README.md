# NCP Finder (天の北極ファインダー)

iPhoneを天の北極（North Celestial Pole: NCP）へ向けるためのWebアプリケーションです。
いつもの場所なら三脚置いただけでseestarの偏差取得を実行できますが、遠征時にちと便利になるプログラムです。
ブラウザの機能を使用しているのでインストールは不要。URLをブックマークするか、QRコードにして三脚に張っておくのもOK

---

## 🌟 主な機能

- **天の北極へのリアルタイムナビゲーション**
  - スマートフォンの画面表側（ガラス面から垂直に伸びる法線方向）を天の北極へ向けるための照準UIを表示します。
  - 目標とのズレ角度（°）および画面の方位・仰角をリアルタイム計算・表示。
  - 誤差が2°未満になると照準が緑色になり、仮合わせ完了を知らせます。
- **GPSによる観測地緯度の自動取得**
  - Geolocation API を使用して観測地点の緯度を自動反映し、目標仰角（= 観測地の北緯）を設定します。
  - 手動での緯度変更・微調整も可能です。
- **方位補正機能**
  - 地磁気の影響やコンパスの偏角に合わせて、方位オフセット（°）を手動で補正できます。
- **iOS / Android 両対応**
  - iOS (Safari) の `DeviceOrientationEvent.requestPermission` および `webkitCompassHeading`、Android 等の絶対方位センサーに対応。

---

## 📱 使い方

1. **HTTPS環境でアクセス**
   - 端末のモーションセンサー・位置情報（GPS）を使用するため、HTTPS配信されたURL（GitHub Pages等）またはローカルホスト（`localhost`）からアクセスしてください。
2. **センサーの開始**
   - 「センサーを開始」ボタンをタップします。
   - ブラウザからモーションセンサーおよび位置情報の許可を求められたら「許可」を選択してください。
3. **スマートフォンの向きを合わせる**
   - 画面の表側（ディスプレイ面）を空に向けます。
   - 照準の黄色い矢印・マーカーの案内に従って、黄色の印が中央の十字（`+`）に重なるように端末の向き・傾きを調整します。
   - ズレが2°未満（「✓ 仮合わせOK」）になれば完了です。

---

## ⚙️ 設定項目

- **観測地点の緯度（北緯 °）**
  - 天の北極の仰角として使用されます。GPS取得失敗時や手動指定したい場合に入力します。
- **方位補正（°：東を＋）**
  - スマートフォンの内蔵コンパスが示す方位と真北にずれがある場合に調整します。

## ⚠️ 注意事項・制限事項

- **磁気干渉について**
  - 周囲の金属、建物、車、電子機器などの影響で電子コンパスに誤差が生じる場合があります。
  - 望遠鏡本体の金属フレームや磁石に近づけすぎないようご注意ください。
- **用途について**
  - スマート望遠鏡（Seestar等）の設置時におけるおおよその導入・仮合わせを想定しています。高精度な極軸合わせを保証するものではありません。
- **ブラウザ要件**
  - iOSをご利用の場合は Safari での利用を推奨します。
  - `DeviceOrientation` API および `Geolocation` API が有効なブラウザが必要です。
